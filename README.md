# Pizza Sales Analysis using SQL

## Project Overview
This project analyzes Pizza Hut sales data using SQL to understand customer ordering patterns, popular pizza types, and revenue trends. The analysis helps identify key business insights for better decision-making.

## Objectives
- Analyze total sales and revenue generated
- Identify top-selling pizza types
- Understand customer ordering behavior
- Find peak order times and sales trends

## Tools & Technologies
- SQL
- MySQL
- Data Analysis

## Dataset
The project uses multiple datasets including:
- Orders data
- Order details
- Pizza types
- Pizza pricing information

## Key Insights
- Identified the most popular pizza categories
- Analyzed revenue contribution by pizza type
- Found peak order times and sales patterns
